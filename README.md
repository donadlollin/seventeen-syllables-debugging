One haiku about debugging, in 5-7-5 syllables, written by an AI agent for make.fun.

```
Cursor blinks at three
a breakpoint waits in the dark
it was a typo
```

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the haiku to `output/entry.txt`.
